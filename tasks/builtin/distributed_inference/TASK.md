# 目标
在去中心化算力网络中的多个节点上并行执行 AI 推理任务，实现高效的大规模推理。

# 描述
这是一个分布式推理任务，需要：
1. 协调多个算力节点
2. 将推理任务分片分发到各节点
3. 收集并聚合各节点的推理结果
4. 返回完整的推理结果

# 输入参数
| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| prompt | string | 是 | 推理提示词 |
| model_path | string | 是 | 模型路径 |
| nodes | array | 是 | 节点ID列表 |
| max_tokens | integer | 否 | 最大生成token数 |
| temperature | float | 否 | 生成温度 |

# 验收标准
- [ ] 所有节点收到推理任务
- [ ] 各节点成功执行推理
- [ ] 收集到所有节点的结果
- [ ] 聚合结果正确返回
- [ ] 任务完成报告生成

# 执行步骤

## 步骤1: 节点准备
- 操作: 检查所有节点状态
- 验证: 节点在线且有足够资源
- 并行: 对所有节点并行检查

## 步骤2: 任务分发
- 操作: 将推理任务分片
- 策略: 按节点数量均分
- 并行: 向所有节点分发

## 步骤3: 并行推理
- 操作: 各节点独立执行推理
- 并行: 所有节点同时执行
- 监控: 监控各节点进度

## 步骤4: 结果聚合
- 操作: 收集各节点结果
- 验证: 验证结果完整性
- 输出: 聚合后的完整结果

# Swarm 配置

## Agent 角色
- **Leader Agent**: 协调任务分发和结果聚合
- **Worker Agent**: 在各节点执行推理任务

## 协作策略
- **层级模式**: Leader 协调 -> Workers 执行 -> Leader 聚合
- **广播模式**: 相同任务广播到所有节点
- **分片模式**: 任务拆分，每个节点处理不同部分

## 配置示例
```json
{
  "swarm": {
    "agent_count": 4,
    "strategy": "hierarchical",
    "roles": {
      "leader": "node_001",
      "workers": ["node_002", "node_003", "node_004"]
    }
  }
}
```

# 约束条件
- **最大执行时间**: 300秒
- **网络要求**: 稳定的P2P连接
- **节点要求**: 至少2个在线节点

# 故障处理
1. **节点离线**: 重新分配任务到其他节点
2. **推理失败**: 重试3次，记录错误
3. **结果丢失**: 请求节点重新计算

# 完成信号
- 所有节点返回推理结果
- Leader 成功聚合结果
- 生成任务完成报告
