# 任务：切分并分发LLM模型

## 目标
将 `/models/llama-7b.gguf` 模型切分为4个分片，并分发到网络中的4个算力节点。

## 描述
这是一个标准的模型切分分发任务。模型大小约4GB，需要均匀切分到4个节点以实现并行推理。每个节点将获得约1GB的分片。

## 输入参数
- **模型路径**: `/models/llama-7b.gguf`
- **目标节点数**: 4
- **目标节点ID**: node_001, node_002, node_003, node_004
- **输出目录**: `./shards/llama-7b/`

## 验收标准（必须全部达成）
- [ ] 模型被成功切分为4个分片，每个约1GB
- [ ] 所有分片生成SHA256校验和
- [ ] 4个分片分别成功传输到对应节点
- [ ] 每个节点验证接收的分片校验和正确
- [ ] 生成分发报告，记录每个分片的位置和状态

## 执行步骤

### 步骤1: 分析模型结构
- **操作**: 使用DecentralizedModel工具分析模型
- **验证**: 获取到模型的层数、参数分布、总大小
- **预期输出**: 模型分析报告

### 步骤2: 确定切分策略
- **操作**: 基于模型结构选择最佳切分策略
- **验证**: 确认切分后的分片大小均衡
- **决策**: 按层切分或按大小切分

### 步骤3: 执行模型切分
- **操作**: 切分模型为4个分片
- **验证**: 生成了4个.shard文件，总大小接近原模型
- **输出**: `./shards/llama-7b/shard_*.bin`

### 步骤4: 生成校验和
- **操作**: 为每个分片计算SHA256校验和
- **验证**: 校验和文件成功创建
- **输出**: `./shards/llama-7b/checksums.json`

### 步骤5: 发现目标节点
- **操作**: 使用IrohComms工具发现网络中的节点
- **验证**: 确认4个目标节点在线且可达
- **输出**: 节点状态列表

### 步骤6: 分发分片到节点
- **操作**: 并行传输4个分片到对应节点
- **验证**: 每个分片传输完成且校验通过
- **重试**: 失败时自动重试3次

### 步骤7: 验证完整分发
- **操作**: 查询每个节点确认分片接收成功
- **验证**: 所有节点报告分片完整且校验通过
- **输出**: 分发验证报告

### 步骤8: 生成最终报告
- **操作**: 汇总所有执行结果
- **输出**: `distribution_report.json`

## 约束条件
- **最大执行时间**: 30分钟
- **单分片最大大小**: 1.5GB
- **网络带宽要求**: 每个节点至少10Mbps
- **重试次数**: 每个传输最多3次

## 故障处理
1. **切分失败**: 检查磁盘空间，清理临时文件后重试
2. **节点不可达**: 跳过该节点，记录到报告，继续分发到其他节点
3. **传输超时**: 增加超时时间，启用压缩传输
4. **校验失败**: 重新传输该分片

## 完成信号
任务完成时，应该在 `./shards/llama-7b/` 目录下生成:
- `shard_001.bin` ~ `shard_004.bin` (分片文件)
- `checksums.json` (校验和)
- `distribution_report.json` (分发报告)
- `COMPLETED` 标记文件
