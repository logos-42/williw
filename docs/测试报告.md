### 2. 数据传递类型

节点可向后端传递的数据：

1. **设备能力数据**
   - cpu_cores: CPU核心数
   - max_memory_mb: 最大内存
   - has_gpu: 是否有GPU
   - gpu_name: GPU名称
   - gpu_memory_total_mb: GPU显存

2. **状态数据**
   - cpu_usage: CPU使用率
   - gpu_usage_percent: GPU使用率
   - memory_usage: 内存使用率
   - battery_level: 电池电量
   - is_charging: 是否充电

3. **训练数据**
   - tick_count: 训练轮次
   - model_version: 模型版本
   - convergence_score: 收敛度
   - sparse_updates_sent/received: 稀疏更新数量
   - heartbeats_sent/received: 心跳数量

4. **拓扑数据**
   - connected_peers: 连接节点数
   - similarity: 模型相似度
   - geo_affinity: 地理亲和度

5. **共识数据**
   - stake_eth/stake_sol: 质押量
   - reputation: 声誉值

### 3. 本地部署

```bash
# 构建镜像
docker build -t williw:latest .

# 使用 docker-compose 启动
docker-compose up -d

# 查看日志
docker logs -f williw-node
```

**直接运行命令**:
```bash
# 编译
cargo build --release

# 运行单节点
./target/release/williw-bin --node-id 1 --quic-port 9235

# 运行多节点（不同终端）
# 终端1:
./target/release/williw-bin --node-id 1 --quic-port 9235

# 终端2:
./target/release/williw-bin --node-id 2 --quic-port 9236 --bootstrap 127.0.0.1:9235
```

## 使用实际后端 API

启动实际后端服务：

```bash
cd williw-workers
python3 -m edge_server.api_server --port 8080
```

发送推理请求：

```python
from interface_layer.app_client import AppClient

client = AppClient(edge_server_url="http://localhost:8080")
result = client.inference(
    model_name="bert-base-uncased",
    model_source="huggingface",
    input_data={"text": "Hello world"},
    parameters={"batch_size": 1}
)
```
